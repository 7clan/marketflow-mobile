# MarketFlow Mobile

A Flutter marketplace application designed to demonstrate production-style mobile engineering across API integration, state management, search/filtering, pagination, persistence, testing, performance, accessibility, and release readiness.

## Planned stack

- Flutter / Dart
- Riverpod
- Dio
- GoRouter
- Local persistence/cache
- Node.js/NestJS + PostgreSQL when practical
